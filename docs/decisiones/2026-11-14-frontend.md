# D5: Frontend

- Estado: aceptada
- Issue: #6

## Contexto
El resultado debe ser **visualmente atractivo** (pitch y video) sin lógica de negocio en el frontend y con costo casi nulo.

## Decisión
- **React + Vite + TypeScript + Tailwind CSS + shadcn/ui**, en **modo oscuro** por defecto (estética de "centro de control").
- **MapLibre GL JS** para el mapa, con un mapa base oscuro gratuito y sin API key. Mapa de calor, pulsos y extrusión 3D nativos, **sin deck.gl**.
- **Recharts** para los gráficos y **Framer Motion** para las animaciones y los contadores.
- Dos vistas en una misma app: **portal del usuario** (mobile-first) y **panel del operador** (escritorio y pantalla grande).
- Datos: **solo del API real**. Polling cada 2–3 s; WebSocket en E7.
- Hosting: ~~S3 + CloudFront~~ **CloudFront está bloqueado en Learner Lab (E0)**. Se usa S3 (almacén versionado) servido por **HTTPS vía API Gateway + Lambda** (la geolocalización y la voz exigen HTTPS). Ver D1.
- Carpeta: `frontend/`. La URL del API se inyecta en el build desde los outputs del stack. Nunca va escrita a mano.

## Consecuencias
- El diseño se itera por entregas (ver `docs/roadmap.md`): cada entrega se despliega y el equipo da feedback.
- Las reglas (umbrales, estados, prioridad) viven **solo** en el backend.
